# PL/SQL Program 14 - Sum of Two Numbers

## Objective

Write a PL/SQL block to:

1. Declare two variables.
2. Assign values to the variables.
3. Calculate the sum of the two numbers.
4. Display the result using `DBMS_OUTPUT.PUT_LINE`.

## Program

Students must write a PL/SQL block similar to:

```sql
SET SERVEROUTPUT ON;

DECLARE
    num1 NUMBER := 10;
    num2 NUMBER := 20;
    total NUMBER;
BEGIN
    total := num1 + num2;

    DBMS_OUTPUT.PUT_LINE('First Number  : ' || num1);
    DBMS_OUTPUT.PUT_LINE('Second Number : ' || num2);
    DBMS_OUTPUT.PUT_LINE('Sum           : ' || total);
END;
/
```

## Explanation

### SET SERVEROUTPUT ON

Enables the display of output generated by `DBMS_OUTPUT.PUT_LINE`.

### DECLARE

The `DECLARE` section is used to declare variables.

```sql
num1 NUMBER := 10;
num2 NUMBER := 20;
total NUMBER;
```

Here:

* `num1` stores the first number.
* `num2` stores the second number.
* `total` stores the calculated sum.

### BEGIN

The `BEGIN` section contains the executable statements.

```sql
total := num1 + num2;
```

This adds the two numbers.

### DBMS_OUTPUT.PUT_LINE

Used to display output.

```sql
DBMS_OUTPUT.PUT_LINE('Sum : ' || total);
```

### END

Marks the end of the PL/SQL block.

```sql
END;
/
```

The `/` executes the PL/SQL block in Oracle SQL*Plus, SQL Developer, or compatible Oracle tools.

## Expected Output

```text
First Number  : 10
Second Number : 20
Sum           : 30
```
